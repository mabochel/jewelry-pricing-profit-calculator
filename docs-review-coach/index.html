The hierarchy

What the old terms meant

ID was only a row number. Removed.

Effective tier was a hidden severity adjustment. Now the app simply explains the suggested severity in plain English.

Scope means one place vs repeated vs throughout. It matters because a repeated minor pattern can become a Moderate weakness.

Practice Cases replaces the old “Learn” tab.

Two distinctions to memorize

Ideas in the wrong order → Content / Document Structure.
Page visually hard to scan → Visual / Readability.

Bad-looking ≠ uneditable. Editability asks whether the real object/content can be revised efficiently.

Rationale structure
